## 2. 范围

### 包含

- 桌面顶栏入口、流程内协助槽、右侧面板、完整任务工作台。
- 主 Agent 自动路由解释、子任务计划、来源与候选审阅。
- 33 个 P0 候选子 Agent 的中文角色、协作卡、贡献和失败表达。
- 5 个 P0 主 Agent 的语义、结果模板及 14 个诊疗环节嵌入。
- 加载、空、部分、过期、断线、审批、阻断、取消和人工接管状态。
- 栅格母版、IP 资产、Token、清单和 QA。

### 不包含

- 前端代码修改、API/状态机实现或数据库设计。
- 移动端、小程序、患者端和 Ambient 录音 UI。
- P1 Diagnosis/Safety/Coding/Message/Ambient/Research 的高保真扩面。
- 未批准的模型、Tool、真实患者数据和真实副作用演示。
