## 2. 主要问题与修复方向

| 优先级 | 当前观察 | v2 修复 |
|---:|---|---|
| P0 | 用户必须在唤起页理解并手工选择旧 Agent。 | 用户选诊疗任务；系统展示自动路由到的唯一主 Agent 和理由。 |
| P0 | 旧目录 6 Agent 与新版 5 主 Agent/33 子 Agent 不一致。 | 临床 UI 采用 5 个主 Agent 结果语义；子 Agent 以步骤展示。 |

| P0 | 完整工作台三栏长期挤压主内容，聊天占中心。 | 8/4 主任务—执行计划布局；来源和技术详情按需展开。 |
| P0 | 候选与实际临床动作的视觉边界不足。 | 紫色候选头、明确来源/未决项；只复制到人工草稿或进入审批。 |
| P1 | 顶栏与右下永久入口可能重复。 | 桌面顶栏为永久入口，右下仅按需 Nudge；待产品确认。 |
| P1 | IP 出现在高风险场景可能弱化严肃性。 | IP 限于入口、空状态和引导；阻断/审批不用拟人化插画。 |
