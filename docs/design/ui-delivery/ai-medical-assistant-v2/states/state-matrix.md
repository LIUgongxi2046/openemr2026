# AI 医助小南 v2 状态矩阵

| 状态 | 触发 | 面板/工作台表达 | 可用动作 | 禁止行为 | 状态 |
|---|---|---|---|---|---|
| `SAFE_EMPTY` | 无患者/就诊/任务 | “安全空上下文”，只展示产品帮助和导航 | 选择患者或任务、关闭 | 展示患者建议、调用临床 Tool | `CREATED` |
| `CONTEXT_LOADING` | 正在建立 ContextLease | 骨架 + “正在建立最小授权上下文” | 取消 | 显示旧患者正文 | `CREATED` |
| `CONTEXT_DENIED` | 无权或用途不允许 | 不泄露对象存在性的权限说明 | 返回人工流程、关闭 | 申请未知通配权限 | `CREATED` |
| `ROUTE_MATCHING` | 识别任务与临床阶段 | 匹配原因占位、低动 loading | 取消匹配 | 伪造预计 Agent | `CREATED` |
| `ROUTE_CLARIFY` | 目标/阶段/患者不唯一 | 单一澄清问题 + 2–4 个业务选项 | 选择、取消 | 默认高风险任务 | `CREATED` |
| `READY_TO_START` | 路由与 Scope 已批准 | 主 Agent、理由、数据范围、步骤、禁止动作 | 开始生成、更换任务、取消 | 隐藏读取范围 | `CREATED` |
| `RUNNING` | root/child 执行 | 步骤 complete/running/pending，显示耗时 | 停止、转人工、打开工作台 | 展示思维链、虚假百分比 | `CREATED` |
| `WAITING_APPROVAL` | 需要具体动作批准 | 精确动作摘要、风险、有效期 | 进入审批、拒绝 | 在面板内模糊一键批准 | `CREATED` |
| `PARTIAL` | 非关键步骤失败且组合允许 | 琥珀“部分完成”，已完成/缺失范围并列 | 查看缺失、转人工；复制待 Q-006 | 使用绿色完整成功样式 | `CREATED` |
| `BLOCKED` | 关键步骤、权限、患者、来源失败 | 红色“已阻断”，原因和解除条件 | 重新授权或返回人工流程 | 继续生成候选 | `CREATED` |
| `FAILED` | 系统/模型/Tool 失败且无安全恢复 | 失败阶段、trace ref、人工替代路径 | 安全重试（若允许）、转人工 | 盲重试副作用 | `CREATED` |
| `CANCELLED` | 用户停止或父取消 | 已停止、已完成范围、未创建候选 | 返回原流程、新建任务 | 自动恢复旧 run | `CREATED` |
| `RECONCILING` | 副作用结果未知 | 蓝灰“正在核验真实状态” | 返回人工流程、查看对账 | 标记成功、重复执行 | `CREATED` |
| `READY_FOR_REVIEW` | 关键步骤和验证通过 | 紫色“候选已生成”，来源覆盖和未决项 | 查看来源、对比、复制/进入审批 | 自动签署/执行 | `CREATED` |
| `EXPIRED` | 患者/版本/权限/时限变化 | 内容只读折叠、明显过期标识 | 以新上下文重新运行、返回人工 | 复用旧批准/候选动作 | `CREATED` |

## 状态组合规则

- `PARTIAL` 是候选完整性，不是完整成功；必须同时显示缺失范围。
- `READY_FOR_REVIEW + partial=true` 只有在所有关键步骤通过、组合明确允许且最终验证通过时成立。
- `BLOCKED` 不提供“忽略并继续”。
- `FAILED` 只在策略标记可安全重试时显示重试；否则只显示人工路径。
- `CANCELLED` 后收到的晚到事件只更新审计，不恢复 UI。
- `EXPIRED` 内容可用于理解历史，但复制、审批和执行全部禁用。

## 数据与网络状态

| 状态 | 处理 |
|---|---|
| 慢网 | 3 秒后显示当前阶段和“可继续原页面工作”，不阻塞业务 |
| 离线 | 停止新 Tool；显示最后事件时间；仅保留人工流程 |
| SSE 断线 | 显示重连，不推测运行终态；恢复后按 sequence 补事件 |
| 重复提交 | 使用同一幂等任务并聚焦现有 run，不创建重复候选 |
| 长文本 | 候选正文在 920px 可读宽内；步骤和来源可展开 |
| 来源不可用 | 显示不可用原因；事实不得标为已验证 |

## 子 Agent 协作状态

| 子 Agent 结果 | 用户状态 | 必须显示 | 主 Agent 处理 |
|---|---|---|---|
| `CREATED/QUEUED` | 准备中 | 等待哪一项上游或何时开始 | 无 |
| `RUNNING` | 协作中 | 角色名、可观察动作、已读来源数、耗时 | 可停止/转人工 |
| `COMPLETE` | 已完成 | 贡献类型、数量、来源入口、接力去向 | 聚合或启动下游 |
| `INCOMPLETE` | 未完整 | 已完成与缺失范围 | 按关键性 partial/blocked |
| `NO_EVIDENCE` | 无足够证据 | 已检查范围和“未生成结论” | 不补写 |
| `BLOCKED` | 已阻断 | 阻断原因和解除条件 | 关键节点阻断主任务 |
| `FAILED` | 失败 | 失败阶段、可否安全重试、人工路径 | 按组合策略 |
| `CANCELLED` | 已取消 | 取消来源和晚到结果不采用 | 停止下游 |

独立核验环节使用单独卡片并标注“非子 Agent”；其失败不能通过子 Agent 重试入口绕过。
