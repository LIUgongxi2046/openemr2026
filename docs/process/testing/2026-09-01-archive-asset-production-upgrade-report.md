# 病案资产中心生产化升级、纵深页面与安全回归报告

- 执行日期：2026-09-01（Asia/Shanghai）
- 范围：病案资产总览、病案目录、扫描编目、完整性与验真、借阅复制、长期保存、资产详情、L5–L7 质量治理与 Agent
- 验收环境：`dev-synthetic`，PostgreSQL 18.4 隔离空库，PC Web `1440×1000`
- 数据库：空库成功执行 232 个 Flyway 迁移，当前版本 V342
- 结论：**本地可执行业务链验收 PASS；真实医院外部系统联调与投产门禁 NO_GO**

## 1. 本轮完成的真实功能

1. 原始文件上传与读回：入库前扫描恶意文件，持久化原始字节、SHA-256、存储提供方和扫描引擎证据；下载时从存储重读而非相信浏览器输入。
2. OCR 与 CDA：OCR 只能由服务端执行并保存文本、置信度和引擎证据；CDA 结论改为服务端校验证据派生，拒绝用户直接伪造 `VERIFIED/FAILED`。
3. 验真与流程硬门：存储重读复算哈希；验真失败、原件缺失、已作废等状态真实阻断借阅、复制和 WORM 封包。
4. 借阅与复制分发：借阅新建、更期、归还；复制包与用途清单不可变哈希；交付时保存接收主体、身份核验、授权依据、复制范围、单独同意、交付通道、专用章号和签收凭证。
5. 长期保存：保留年限排期、封包、对象锁证据、到期日只能延长不能缩短、封包后不能解锁/作废、抽样恢复重读。
6. 二至七级页面：原有二级菜单和资产详情保留；增加绑定资产、租户、机构、院区的 L5 整改动作、L6 证据束、L7 独立复核与 Agent 候选建议。记录支持新建、编辑、逻辑作废、版本并发与审计/Outbox。
7. Agent 边界：当前是确定性规则驱动的真实候选建议生成器，会读取当前证据水位并写入候选建议；它不伪称已调用外部大模型，不能自动改写病案事实或复核结论。

## 3. 最新测试/安全报告问题的修复

2026-08-31 报告记录的病案资产 P1 问题是：浏览器脚本使用延迟 Promise，导致未捕获异常且未观测到预期 POST。本轮已修复：

- 请求等待改为 `page.waitForResponse`，并在创建 Promise 时立即捕获成功/失败结果，不再产生延迟未处理异常。
- 登录账号改为数据库真实生成凭据且仅具有病案角色的 `shulan.tian`，同时支持环境变量覆盖。
- 选择器与当前实现一致：扫描页和借阅/长期保存操作是页面级按钮，不再误当成表格行内按钮。
- 脚本扩展到 L5–L7 真实写入与 Agent 候选建议，失败必须落盘报告并返回非零退出码。
- 扫描页删除硬编码“高拍仪 03 在线”；签名/CDA 页删除无证据的“院内 CA + TSA”和固定校验器版本声称。

## 5. 安全结论

本地低影响验证未发现本次改动引入的可复现高危问题，以下门禁已有自动化证据：

- 未授权读/写/下载拒绝，跨父对象和跨院区写入拒绝。
- EICAR 测试载荷被恶意文件适配器拒绝，扫描结论不接受前端传入。
- 合成 CDA 校验器使用禁用 DTD/外部实体的 XML 解析配置，验证结论与证据哈希由服务端生成。
- 资产内容哈希、身份与 WORM 保留期有数据库级防篡改触发器。
- `prod` 启动必须提供 HTTPS OCR/CDA 端点、ClamAV 主机/端口、S3 区域/桶/密钥引用和 Object Lock 配置；缺失或明文 HTTP/内联密钥时 fail closed。

本结论仅覆盖隔离合成环境，不等价于生产渗透、真实 IdP 鉴权、密钥轮换、备份恢复或供应商合规证明。
