# 模拟接口生产化仿真收口报告

- 日期：2026-08-31
- 范围：“模拟接口”菜单、13 个仿真工作台、3—7 级钻取页面、配置生命周期、运行证据与安全规则 Agent
- 模块结论：GO（合成仿真边界内）
- 真实外部系统结论：NOT IN SCOPE / NOT COMPLETE

## 已完成的生产化仿真能力

1. 执行端不再直接调用内存生成器；必须绑定 `ACTIVE + VALID + APPROVED` 的 `MOCK_INTERFACE_PROFILE`。
2. 运行记录、事件时间线、Agent 结论、SHA-256 证据摘要、审计事件和 outbox 事件持久化。
3. `Idempotency-Key` 强制校验；同键同请求返回同一运行 ID、请求 ID、产生时间和证据哈希，同键异请求返回 409。
4. 仿真配置变更限定系统管理员、临床管理员或集成运维岗位；执行和证据查询必须具有有效岗位赋权。
5. 请求明确禁止真实 PHI；布尔值、字符串绕过均阻断，患者/就诊 ID 仅允许隔离的合成 UUID 命名空间。
6. 合成数据不再是每菜单两条固定记录；默认 36 条，可配 12—200 条，基于业务种子可重放生成。
7. 中国三级医院语义已补全：院区/科室、WS/T 846/847 配置档案、检验危急值复核-报告-接收-处置闭环、医保模拟对账、设备校准/时钟/绑定、病案保存期、治疗双签、CA 合成证据无法律效力。
8. 安全规则 Agent 已完成 PASS / REVIEW / BLOCK 决策和人工复核建议；它是确定性规则 Agent，不是 LLM，且永不写入真实临床事实。
9. 3—7 级页面已提供配置详情、场景治理、运行历史、运行详情/Agent 时间线、证据核验，数据来自后端持久化接口。

1. 未接入医院真实 OIDC/MFA、LIS、PACS、HIS/医保、CA、区域平台、设备网关、ASR 和模型厂商凭据；因此这是“可审计的生产化仿真控制面”，不是真实外部系统已联调。
