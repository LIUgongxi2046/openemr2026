# AI医助小南前端优化审计

- 日期：2026-08-26
- 页面：`http://127.0.0.1:4178/app/index.html#ai-center`
- 范围：小南中窗、右侧窗、医生可见文案、桌面/矮屏/移动端响应式
- 目标：医生快速选择协作任务、查看协作进度并随时输入任务，不暴露治理实现术语

## 总体结论

优化通过。已删除弹窗内的“安全边界”“A1 候选制”“ContextLease”“route”和“Agent 治理”等治理或工程文案；右侧窗从会横向撑出容器的布局，改为无横向溢出的自适应四区网格。关闭按钮、窗口模式、协作任务、对话区和输入操作在所有验收视口均可见或可独立滚动。

## 验收步骤

1. **打开中窗 — 健康**
   - 页面只呈现“协作团队、当前进度、协作者、开始协助”等医生语言。
   - 5 个协作组和 33 位协作者仍保持可见，子 Agent 感知没有丢失。
   - 证据：`04-center-after-1280x800.png`

2. **切换右侧窗 — 健康**
   - 右侧窗、Header、任务区、会话区、输入区的 `scrollWidth` 均等于 `clientWidth`。
   - 关闭按钮、模式切换和主操作按钮完整显示。
   - 证据：`05-side-after-1280x800.png`

3. **缩短到 1024 × 600 — 健康**
   - 矮屏启用紧凑 Header 和输入区；任务区独立滚动。
   - 右侧窗 `scrollHeight = clientHeight = 600`，主按钮底部为 592，未超出视口。
   - 证据：`09-side-after-1024x600.png`

4. **缩小到 390 × 844 — 健康**
   - 右侧窗自动切换为全屏工作面板，左边缘为 0，不再裁切头像。
   - 输入区和两个操作按钮固定可见，任务区与会话区分别滚动。
   - 证据：`10-side-after-fixed-390x844.png`

5. **进入小南完整工作台 — 健康**
   - 页面统一使用“诊疗场景、协作团队、协作任务、协作者”等医生语言，不显示运行模式、租约、候选制或内部 Agent 编码。
   - 主 Agent、子 Agent 与运行事件仍完整保留，并以协作组、协作者和当前进度的形式呈现给医生。
   - 证据：`11-workspace-after-1280x800.png`

## 缺陷闭环

| 问题 | 优先级 | 处理结果 |
|---|---|---|
| 弹窗出现安全边界、A1、ContextLease、route 等医生无关术语 | P1 | 已全部从医生弹窗模板移除；内部安全提示仍保留在 Agent 请求上下文中 |
| 460px 右侧窗内部被撑到 509px，导致按钮和内容越界 | P1 | 所有网格子项增加 `min-width: 0`，Header 改为响应式网格，宽度完全收敛 |
| 1024 × 600 下输入按钮底部超出视口 20px | P1 | 增加矮屏布局，最终按钮底部 592px |
| 390px 下右侧窗左移 15px，头像被裁切 | P1 | 移动端改为 `left: 0; right: 0; width: auto` |
